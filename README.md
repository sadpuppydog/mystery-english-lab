# 英語實驗室密室命案（React + Vite）

依 Figma 偵探版原型做成的網頁遊戲：兩個關卡（第一關 HOW 找犯案方式、第二關 WHO 找兇手），用 Grammar Bingo 累積學習分數、解鎖線索，最後推理。

## 執行方式

**只想玩**：先解壓縮，雙擊專案資料夾裡的「啟動遊戲.cmd」。它會啟動本機網站，並用 Google Chrome 開啟遊戲；首次使用會安裝專案依賴。

**要改程式**（需要 Node.js 18 以上）：

```bash
cd mystery-lab
npm install
npm run dev            # 終端機會顯示網址（通常是 http://localhost:5173），用瀏覽器打開
npm run build          # 輸出到 dist/，可放到任何靜態網站空間
```

注意：專案裡的 index.html 不能直接雙擊打開（會一片空白），請使用「啟動遊戲.cmd」或 `npm run dev`。

示範帳號：`s1120345` / `detective01`，也可以自己註冊，或按「訪客試玩（不存檔）」。
帳號和進度都存在瀏覽器的 localStorage（原型用，沒有後端）。

## 隨機性（依老師建議）

- **抽格子**：盤面不能自己點格子挑戰，要按右下角「抽格子」，系統從還沒挑戰的格子隨機抽一格，抽到哪格就做哪格。
  - 一般格：抽到就要挑戰（3 題）。
  - 事件格：可以接受或略過（略過的格子算已挑戰，但沒有分數）。
  - 抽到的結果會先存檔，重新整理網頁也不能重抽。
  - 已完成的格子可以點開「題目回顧」。
- **題組隨機**：每個文法主題有兩套題目，第一關隨機抽一套，第二關自動用另一套。
- **選項順序隨機**：每格開始時打亂選項與推理卡片的順序。

## 遊戲規則（程式裡的數值）

數值集中在 `src/game.js` 的 `SCORE` 等常數，要調整只改這裡。

| 項目 | 數值 |
|---|---|
| 一般格 3 題全對 | 學習分數 +100、金幣 +5 |
| 事件格成功 | 學習分數 +200、金幣 +20、取得事件紙條 |
| 事件格失敗 | 金幣 −20（最低 0） |
| Bingo 連線（橫、直、斜共 12 條，只算完成的格子） | 學習分數 +150 |
| 線索解鎖 | 1,500 依選的線索數平均切；選 n 個線索會拿到最後 n 個（最關鍵的）證據 |
| 推理 | 學習分數 ≥ 1,500 開放，一關只能推理一次 |
| 遊戲分數 | 1000 − 線索數 × 200，猜對再 +200；沒推理不計 |
| 協助分數 | 每關 1,500；提示 −5（同題不重複扣）；AI 每個模型每題 −5；不足時仍可問 AI |
| 25 格全挑戰但未達 1,500 | 800–1,499 直接揭曉；800 以下先做 3 題補救學習再揭曉 |
| 最終星級（兩關學習分數合計） | 5★ ≥6000、4★ ≥5000、3★ ≥3600、2★ ≥2400、1★ 以下 |

## 專案結構

```
src/
  data/
    topics.js    22 個文法主題 × 2 套題（找錯句、找錯誤位置、文法推理）＋盤面配置
    events.js    3 個事件（限時、6 選 1、多選）的題目與備用題、3 種道具
    story.js     開場、兩關線索、推理選項、揭曉動畫文字、補救學習、遊戲規則
  game.js        規則與計分、連線判斷、線索解鎖、出題、AI 預設回覆、存檔
  store.jsx      遊戲狀態（React Context），所有動作都在這裡
  App.jsx        畫面切換
  components/    共用元件（圖示、視窗、標題列、證據資料夾、背包、AI 面板）
  screens/
    Auth.jsx     登入／註冊／忘記密碼
    Intro.jsx    首頁、開場、規則、選線索、第二關開始
    Board.jsx    Bingo 盤面與抽格子
    Cell.jsx     一般格作答（3 題）、結果、題目回顧
    Event.jsx    事件說明、準備、作答（含計時與道具）、結果、道具商店
    Ending.jsx   推理、揭曉、結算、補救學習、最終結算
```

## 要改題目時

- 一般格：改 `src/data/topics.js`。每套題的欄位：
  - `w` 錯誤句、`ok` 三個正確句
  - `fix` [錯誤, 改法]、`d2` 三個干擾改法
  - `cue` 線索卡、`rule` 文法卡、`cards` 干擾卡
  - `why` / `tip` 解說、`hint` 提示、`ex` 例句
- 事件：改 `src/data/events.js` 的 `sets.A`（第一關）與 `sets.B`（第二關）。
- 劇情與線索：改 `src/data/story.js`。

## 目前的原型限制

- AI 輔助是依題目資料預先寫好的回覆（不直接給答案），還沒有串接真正的 AI API。
- 照片都是占位圖（`[照片：…]`），之後換成真的圖片即可。
- 帳號與進度存在瀏覽器裡，換瀏覽器或清除資料就會不見；正式版需要後端。
- 事件挑戰進行中重新整理網頁，會從該事件第 1 題重新開始。
- 測試用：網址加 `?debug` 時，可以在瀏覽器主控台用 `window.__mlab` 查看與修改狀態。
